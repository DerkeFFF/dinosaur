# dino-master

автономный бот для chrome dino на основе нейросети neat. обучение проходит в python-симуляторе, а готовую модель можно запускать в настоящей игре в google chrome.

## что умеет проект

- обучает популяцию нейросетей и отбирает лучшие;
- распознаёт ближайшие препятствия и оценивает время до столкновения;
- использует прыжок, приседание и быстрое приземление;
- автоматически сохраняет лучший найденный геном;
- позволяет наблюдать за ботом в chrome и проверять модель.

## требования

- python 3.12 или новее;
- [uv](https://docs.astral.sh/uv/);
- google chrome и доступ к интернету для запуска в браузере.

## установка

открой PowerShell в папке проекта и выполни:

```powershell
uv sync
```

## запуск готового динозаврика

модель проекта находится в `models/best.pkl`.

если chrome установлен в стандартную папку, в PowerShell выполни:

```powershell
$env:DINO_CHROME_EXECUTABLE = "C:\Program Files\Google\Chrome\Application\chrome.exe"
uv run dino-spectate --genome models/best.pkl
```

если переменная уже настроена, достаточно второй команды:

```powershell
uv run dino-spectate --genome models/best.pkl
```

бот будет играть в отдельном окне chrome. для остановки нажми `Ctrl + C` в терминале.

## повторное обучение

если захочешь обучить новую модель, используй:

```powershell
uv run dino-train --generations 100 --population 750 --max-steps 40000 --episodes-per-gen 5 --best models/best.pkl
```

лучшая модель сохраняется в `models/best.pkl` при появлении нового рекорда. команда перезапишет этот файл новой обученной моделью.

## проверка модели

для проверки нескольких раундов в настоящем chrome и сохранения статистики:

```powershell
uv run dino-eval --genome models/best.pkl --episodes 3 --max-steps 40000 --out eval.json
```

## визуализация симулятора

для просмотра модели во внутреннем python-симуляторе установи дополнительную зависимость и запусти:

```powershell
uv sync --extra viz
uv run dino-visualize --genome models/best.pkl
```

## структура проекта

- `models/best.pkl` - итоговая обученная модель;
- `src/dino_master/` - код симулятора, обучения, восприятия и запуска в браузере;
- `src/dino_master/neat.ini` - настройки neat;
- `tests/` - автоматические тесты;
- `docs/` - демонстрационная веб-страница и файлы игры;
- `scripts/` - вспомогательные скрипты.

## примечание

fitness - внутренняя оценка качества нейросети во время обучения. это не количество очков в chrome и не гарантия безошибочной игры. для оценки поведения модели запускай её через `dino-spectate` или проверяй с помощью `dino-eval`.
